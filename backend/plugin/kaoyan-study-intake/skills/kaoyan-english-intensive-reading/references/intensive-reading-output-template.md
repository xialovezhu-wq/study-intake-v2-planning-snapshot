# 精读输出模板

用于直接讲解时的逐句翻译、文章页精翻记录和长难句说明。学习引导模式先使用 sentence-output-template.md 的单问题格式；写入文章页时可展开候选表。

## 逐句聊天输出

```md
原句：

自然中文翻译：

句子结构：
- 主干：
- 修饰：
- 逻辑：

核心词组 / 搭配：
- item：本句意思；处理建议

长难句点：
- 难点：
- 下次动作：

候选判断：
- 长期库候选 / 不建议入库 / 不背单词候选：
- 理由：
```

## 写入文章页的候选区

```md
### 本句抠词 / 词组候选

| item | 类型 | 本句意思 | 为什么抠出 | 后续处理 |
|---|---|---|---|---|
| 待补充 | 单词/词组/熟词僻义/写作表达 | 待补充 | 影响理解/用户明确不会/固定搭配/写作价值 | 长期库候选/不背单词候选/不建议 |

### 本句句型 / 结构候选

| 结构 | 原句对应 | 用户问题 | 复习提醒 | 后续处理 |
|---|---|---|---|---|
| 待补充 | 待补充 | 待补充 | 待补充 | 句式卡候选/CSV句型候选/仅文章候选 |
```

## 白天候选判断短语

- `长期库候选`：有长期价值和来源证据，但尚未经过精确日期的日终正式编纂。
- `不建议入库`：专名、极低价值背景词、过于简单、语境不可迁移、或写作不自然。
- `不背单词候选`：用户卡住但长期价值不足，适合后续导出或阅读识别，不直接写 `master_bank.csv`。

当前句解决后附上 quick-capture 真实 receipt；本模板本身不写文章页或任何正式数据。
