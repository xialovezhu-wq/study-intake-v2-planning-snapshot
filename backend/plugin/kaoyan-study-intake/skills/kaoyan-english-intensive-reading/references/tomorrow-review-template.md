# 明日复习模板

仅在用户明确要求更新明日复习、记录当前复盘转入项，或授权把指定内容加入短期复习时使用。阶段总结或正式入库本身不自动授权写入本文件。

## 写入前检查

1. 读取 `review/tomorrow_review.md`。
2. 读取 `bank/mastered_items.csv`，过滤已掌握 item。
3. 同一天只保留一个 `## YYYY-MM-DD 明日英语碎片复习` 标题。
4. 不更新 `review/weekly_review.md`，除非用户明确要求周复盘。

## 采用句型

- 使用句式卡时写：`SP-NNN｜骨架`。
- 引用 SP-id 时必须给结构拆解。
- 没有合适句式卡时写：`无（本次无合适句式卡）`。SP 可选，不影响四层地基的其他必需证据。
- 只有通过 `schema/reference_grounded_examples.md` 的新例句才可写入“旧词联动例句”。缺用户证据、source_sentence 或任一必需参考层时，写明状态并留空例句。
